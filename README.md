**Notes AI** یک وب‌اپلیکیشن مینیمال و پیشرفته با زبان طراحی اختصاصی اپل (Apple-style Minimalism) و الهام‌گرفته از کامپوننت‌های مدرن [Devigner UI](https://ui.devigner.cc/components) است. این فرانت‌اند به طور کامل به بک‌اند جنگو روی سرور Render متصل شده و تمامی قابلیت‌های آموزشی هوش مصنوعی را در محیطی یکپارچه، تمیز و واکنش‌گرا (RTL) ارائه می‌دهد.

---

## 🎨 ویژگی‌های ظاهری و طراحی (Apple & Devigner UI Aesthetic)

* 🤍 **پالت رنگی مینیمال اپل:** پس‌زمینه سفید تمیز (`#FAFAFC`) با افکت‌های شیشه‌ای بلورین (Glassmorphism & Frosted Glass).
* 💜 **رنگ اکستنت بنفش شیک:** مطابق پوستر رسمی (`#7C3AED` / violet-600) با هاله‌های ملایم نور (Radial Purple Glow).
* 🏷 **نشان‌های شناور (Pill Badges):** کامپوننت‌های مدرن الهام‌گرفته از Devigner UI Badge با نقطه‌های تپنده (Pulsing Dots) و شمارنده‌های مونو.
* 📋 **دکمه‌های کپی متحرک (Copy Buttons):** کپی یکپارچه متون جزوه و فرمول‌ها با فیدبک انیمیشنی رنگ سبز و آیکون تیک.
* 📐 **رندرر فرمول‌های ریاضی و جداول:** پشتیبانی کامل از $\LaTeX$ با موتور KaTeX و تفکیک بلوک‌های کد و جداول تحلیلی.
* 🃏 **فلش‌کارت‌های سه‌بعدی:** چرخش کارت‌ها با افکت سه‌بعدی (3D Flip Animation) همراه با دکمه‌های ناوبری سریع.

## 🚀 دو بخش اصلی سامانه (UX Architecture)

### ۱. ضبط کلاس درس (`/record`)
* **تشخیص خودکار زنگ جاری (`current_bell`):** تشخیص هوشمند اینکه کلاس ۱۲ ریاضی هم‌اکنون در چه درسی قرار دارد، بدون نیاز به انتخاب دستی.
* **رکوردر زنده وب (Web MediaRecorder):** ضبط صدای کلاس در لحظه همراه با نشانگر تپنده `REC` و موج‌های صوتی متحرک (Soundwave Bars).
* **آپلود چندتکه‌ای (Chunking):** تفکیک خودکار ویس‌های طولانی به قطعات ۱۰ الی ۱۵ دقیقه‌ای و ارسال امن به اندپوینت `/api/v1/sessions/{id}/chunks/`.
* **پشتیبانی از انواع فایل صوتی:** امکان انتخاب و آپلود فایل‌های `.m4a`، `.mp3`، `.wav` و `.webm`.
* **کلید نهایی‌سازی (Finalize):** شروع پایپلاین Map-Reduce بک‌اند برای استخراج جزوه، نکات امتحانی و آزمون.

### ۲. آرشیو هوشمند دروس و جلسات (`/archive`)
* **مرحله ۱: انتخاب کلاس و درس:** مشاهده کارت‌های دروس با رنگ‌بندی اختصاصی، نام استاد، کد درس و کلاس، همراه با فیلتر جست‌وجوی لحظه‌ای.
* **مرحله ۲: لیست جلسات هر درس:** مشاهده وضعیت پردازش هر جلسه (`تولید شده`، `در حال ضبط`، `در حال پردازش`) و برچسب‌های محتوایی.
* **مرحله ۳: اتاق مطالعه جلسه (`/archive/[courseId]/[sessionId]`):** دارای ۶ تب ناوبری شناور اپل:
  1. 📝 **جزوه و خلاصه:** خلاصه اجرایی، برچسب‌های مباحث کلیدی، متن کامل مارکداون به همراه فرمول‌های $\LaTeX$ و دانلود مستقیم فایل `.md`.
  2. 🎯 **شکارچی نکات امتحانی (Exam Tips):** کارت‌های برجسته با برچسب‌های اولویت (`CRITICAL` حیاتی با افکت آتشین، `IMPORTANT` و `NORMAL`) همراه با جمله تأکیدی استاد سر کلاس.
  3. 🧪 **آزمون ۴ گزینه‌ای و کارنامه:** پاسخ‌دهی تعاملی به سوالات تستی، ثبت نام دانش‌آموز، تصحیح خودکار آنلاین و محاسبه درصد نمره با توضیحات تشریحی.
  4. 🗂 **فلش‌کارت‌های مرور سریع:** مرور شب امتحان با کارت‌های تعاملی پشت‌ورو شونده.
  5. 💬 **دستیار هوشمند درس (RAG مشابه NotebookLM گوگل):** پرسش و پاسخ متنی زنده با استناد به جلسات درس و پیشنهاد سوالات آماده.
  6. 🎙 **فایل‌های صوتی و رونوشت:** مشاهده وضعیت تکه‌های Whisper STT، پخش آنلاین صوت هر قطعه و دانلود فایل‌های متنی.

## ⚙️ متغیرهای محیطی (`.env` و `.env.local`)

آدرس اتصال به بک‌اند به صورت ماژولار تعریف شده است:

```env
NEXT_PUBLIC_API_URL=https://noteai-o24g.onrender.com
```

## 🛠 راهنمای اجرا در محیط توسعه (Local Development)

```bash
# نصب پکیج‌ها (در صورت نیاز)
npm install

# اجرای سرور توسعه محلی
npm run dev
```

سپس در مرورگر خود آدرس زیر را باز کنید:
👉 `http://localhost:3000`
